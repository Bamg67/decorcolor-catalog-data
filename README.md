# decorcolor-catalog-data

Версионируемый каталог основных цветов товаров [decor-opt.com.ua](https://decor-opt.com.ua/).
Данные предназначены для DecorColor и других проектов, которым нужен поиск товара
по измеренному цвету.

## Файлы

- `data/catalog-colors.json` — основной машиночитаемый каталог.
- `data/catalog-colors.csv` — плоская таблица для импорта и анализа.
- `data/decor_opt_product_colors.xlsx` — таблица с цветовыми образцами для ручной проверки.
- `data/manifest.json` — версия, дата, количество записей и SHA-256 каталога.

Каждая строка содержит отдельные ссылки на русскую (`product_url`) и, если перевод
существует, украинскую (`product_url_uk`) карточки. Цвет фотографии рассчитывается
один раз для обеих страниц. Отсутствующая украинская карточка остаётся пустой.

Приложению достаточно сначала получить небольшой файл:

```text
https://raw.githubusercontent.com/Bamg67/decorcolor-catalog-data/main/data/manifest.json
```

Если `version` изменилась, приложение скачивает `catalogUrl`, проверяет `sha256`
и только после успешной проверки атомарно заменяет локальный каталог.

## Сопоставление цвета

`HEX` и `Hue` служат для быстрого просмотра. Для окончательного сравнения нужно
использовать CIE L*a*b*: `deltaE <= 10` означает вероятное совпадение, диапазон
`10 < deltaE <= 15` требует визуальной проверки. Для нейтральных цветов Hue
отсутствует; используются светлота L* и deltaE.

Перед выделением основных цветов алгоритм исключает средне-серые нейтральные пиксели
студийного фона. Чёрные и белые товары сохраняются. Если объект нельзя надёжно
отделить от фона (например, он прозрачный), строка остаётся без HEX и получает статус
«Требует проверки».

Цвет вычислен по фотографии и зависит от освещения, бликов, прозрачности товара
и фона. Каталог ускоряет поиск кандидатов, но не заменяет контроль физического образца.

## Обновление

Workflow `Update catalog` запускается вручную или по понедельникам. Он:

1. перечитывает карту и действующие разделы сайта с паузой между запросами;
2. повторно использует цвета, если URL карточки и фотографии не изменились;
3. скачивает и анализирует только новые или изменённые фотографии;
4. сопоставляет точные ссылки из украинских разделов без повторной загрузки фотографий;
5. проверяет полноту и уникальность данных;
6. обновляет JSON, CSV, XLSX и манифест одним коммитом.

Ручной запуск:

```bash
python -m pip install -r requirements.txt
python scripts/scan_catalog_colors.py --work-dir .cache/catalog_scan \
  --output build/product_colors.json --previous data/catalog-colors.json --pause 1.5
python scripts/enrich_uk_links.py build/product_colors.json --work-dir .cache/catalog_scan --pause 1.5
python scripts/publish_catalog.py build/product_colors.json data
```
