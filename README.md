# decorcolor-catalog-data

Каталог основных цветов товаров [decor-opt.com.ua](https://decor-opt.com.ua/) для DecorColor и проектов,
которым нужен поиск товара по цвету. Обновляется еженедельно.

## Файлы

- `data/manifest.json` — версия, дата, количество записей и SHA-256 каталога.
- `data/catalog-colors.json` — основной машиночитаемый каталог.
- `data/catalog-colors.csv` — та же таблица для импорта и анализа.
- `data/decor_opt_product_colors.xlsx` — таблица с цветовыми образцами для ручной проверки.

Каждая строка содержит ссылки на русскую (`product_url`) и украинскую (`product_url_uk`, если есть) карточки.

## Обновление

Сначала получите небольшой файл

```text
https://raw.githubusercontent.com/Bamg67/decorcolor-catalog-data/main/data/manifest.json
```

Если `version` изменилась — скачайте `catalogUrl`, проверьте `sha256` и только после этого замените локальный каталог.

## Сопоставление цвета

Сравнивайте в CIE L*a*b*: `deltaE <= 10` — вероятное совпадение, `10 < deltaE <= 15` — требует визуальной
проверки. Цвет вычислен по фотографии и зависит от освещения, бликов и прозрачности товара: каталог ускоряет
поиск кандидатов, но не заменяет физический образец.
